# Supplementary Materials for VHT
This repository provides the supplementary materials for our paper:

“VHT: A Mechanism-Guided IoT-enabled Virtual Instrument for Biopharmaceutical Process Soft Sensing”

## Overview
The main purpose of this repository is to present:

supplementary experimental data,
detailed experimental results,
additional benchmark comparisons,
and related descriptions that support the findings reported in the manuscript.
These materials are provided to improve the transparency and reproducibility of our study.

## Contents
This repository may include:

experimental result tables,
supplementary figures,
benchmark comparison results,
dataset descriptions,
and other materials referenced in the paper.
Note on Code Availability
Due to confidentiality requirements associated with our commercial collaboration, the core implementation code of the proposed VHT framework cannot be publicly released at this stage.

The code contains components related to proprietary technical development and is therefore temporarily restricted from disclosure.

Once the relevant commercial confidentiality limitations are lifted, we plan to release the core code in a future update.
